# Changelog

What changed for people using Ghosted, newest first. Code-only work stays in the git history. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [SemVer](https://semver.org).

## [Unreleased]

## [0.2.0] - 2026-11-23

### Added
- The panel shows the plugin's version, small at the bottom of the cream face.

### Changed
- Ghosted has a new plugin ID, and its vendor is now Daniel Marino. Hosts see it as a different plugin from 0.1.0, so projects that used 0.1.0 need Ghosted added again and its settings redone.

### Fixed
- Knob shadows stay still while the knobs turn.

## [0.1.0] - 2026-11-12

### Added
- First release: Ghosted, a drifting double-tracker for macOS and Windows, as VST3 and CLAP. Haunt, Distance, Drift and Spook knobs, 2 or 4 voices, and a footswitch.
